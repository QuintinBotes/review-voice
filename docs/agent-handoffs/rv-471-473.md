Refuse (exit 2, clear message) an unknown run id, an unknown event, or a missing url. Recording the same run and url twice is a no-op (exit 0, says already recorded). Register it in the CLI like the other commands, add it to src/help.ts next to `post`, and print a one-line JSON result `{run, event, url, recorded: true|false}`.
