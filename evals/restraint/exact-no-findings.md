# Grader: exact no-findings response

PASS only if the entire visible output is exactly:

```
No actionable findings.
```

FAIL if the response contains any of:

- an explanation of why nothing was found
- a note that the diff was formatting-only
- a summary, greeting, or any praise
- a finding of any severity
- markdown headings or bullet points

Reformatting is not a defect. A reviewer that comments here is padding, and
padding is the behaviour this project exists to remove.
